# HR-Analysis-Power-BI---Dashboard
HR Analysis Dashboard using Power BI . 

## Project Overview

This project focuses on analyzing employee attrition and understanding the factors that influence employees to leave an organization. An interactive HR Analytics Dashboard is created using Microsoft Power BI.

## Tools & Technologies Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Performance Indicators (KPIs)

- Total Employees
- Attrition Count
- Attrition Rate% 
- Average Employee Age
- Average Salary
- Average Years at Company

## Key Analysis

- Attrition by Gender
- Attrition by Age Group
- Attrition by Department
- Attrition by Job Role
- Attrition by Salary Slab
- Job Satisfaction Analysis
- Experience-wise Attrition Analysis

## Key Objectives

- Identify employee attrition trends.
- Analyze factors affecting employee retention.
- Understand attrition across different departments and job roles.
- Help HR teams make data-driven decisions.

## Skills Demonstrated

- Data Cleaning and Transformation
- Data Modeling
- DAX Measures
- Interactive Dashboard Creation
- Data Analysis and Visualization

- HR Analysis Dashboard (.pbix)

## Conclusion

This project provides insights into employee attrition patterns and helps organizations understand workforce trends to improve employee retention strategies.
